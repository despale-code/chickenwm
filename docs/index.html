ChickenWM

A Hyprland-style tiling desktop for Windows.
Programs Details GitHub

Install

Paste this into PowerShell. It downloads each program's source, builds it on your machine and installs it for your user. No administrator rights needed.

PS> irm https://despale-code.github.io/chickenwm/install.ps1 | iex
  • You pick which programs to install. The core is always included; Hen Browser, the file explorer and the others are optional.
  • Rust is installed for you if it's missing (the official rustup installer). Building takes a few minutes the first time.
  • Every program gets a Start Menu entry and an App Paths registration, so Windows Search, Win + R and the ChickenWM launcher can find it.
  • Run the same command again to update. Uninstall from Settings › Apps › ChickenWM.

Programs

Each program lives in its own repository. They talk to each other over a named pipe, and the daemon, rooster, starts and supervises them.

Details

Requirements

  • Windows 10 or 11, 64-bit
  • Hen Browser needs the WebView2 runtime (part of Windows 11)
  • About 2 GB free for the first build

Choosing programs without the menu

Set these before running the command:

  • $env:CHICKENWM_COMPONENTS = "henbrowser,chickenwm-files"
  • $env:CHICKENWM_ALL = "1" — every optional program
  • $env:CHICKENWM_YES = "1" — no questions
  • $env:CHICKENWM_DIR = "D:\Apps\ChickenWM"

If something goes wrong

Ctrl + Alt + Shift + Esc is the emergency restore: it puts Explorer back and stops ChickenWM. Uninstalling also restores Explorer first. Your settings stay in %USERPROFILE%\.config\chickenwm.
